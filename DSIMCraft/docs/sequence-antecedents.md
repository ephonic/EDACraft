# 有限序列作为蕴含前件（M140）

单时钟 property 支持 `a ##N b |-> c`、`|=>`，以及已支持的无形参命名 sequence、嵌套分组和固定正数连续重复，前后件均可组合有限 `##N`、`[*N]` 与采样函数。例如：

```systemverilog
sequence request; req ##1 valid; endsequence
assert property (@(posedge clk) disable iff (reset)
                 request |=> ready ##1 done);
```

每拍启动一个独立尝试。前件任一阶段不满足，尝试以空成功结束，默认不执行 pass/cover 动作；只有完整匹配前件才检查后件。`|->` 的后件起点在前件匹配的终点，`|=>` 再后移一拍，后件自己的前导延迟继续相加。`##0` 的多个条件在同一采样槽检查。X/Z 不算布尔匹配，四态比较表达式仍按自己的值判定。

复用既有 Preponed 采样、Observed 检查及 Reactive 动作机制；异步 disable iff 取消前后件的全部未完成尝试。整个阶段列表及前后件分界属于 Sim 的状态，checkpoint/预测复制会保存它们。没有保存 AST 指针、共享可变匹配队列或新建宿主全局状态。仅使用多阶段前件的生成程序启用 `DSIM_PROPERTY_ANTECEDENT_ENABLED`，其他 property 仍使用已有触发路径；有该宏时也可混用标量前件。

AST 的前件、后件分别放在条件节点的两个有所有权的语句分支中，表达式仍处于表达式槽，沿用实例克隆、词法绑定和清理遍历。命名声明不因多处引用转移所有权。RTL parser 独立修改，门级 parser 未改。Bison 3.8.2 重新生成，冲突数仍为原有 76。

受限单时钟确定长度序列。固定重复数 1..256；每侧至多 256 阶段。多阶段前件连同后件至多 256 个显式阶段、总跨度（含非重叠偏移）至多 65536 拍。单阶段零延迟前件降为原布尔触发器，不占阶段槽，保留历史后件 256 阶段上限。范围/零次/无界重复、or/and/intersect 等非确定序列组合、局部变量、序列形参、显式序列时钟、多时钟/嵌套 temporal property 和完整 SVA 尚未实现。前件不能使用前导 `##N`。

测试包含独立的逐起点终点预期、同拍条件、失败前件的空成功、旧布尔触发器混用、采样历史、异步取消、词法遮蔽/跨实例/generate 克隆、边界和真实双分区。每个模型对比 serial/time wheel/threads=2 全部逐信号有序波形及预测提交/回滚；基本模型另覆盖预算中断续跑和检查点重复恢复。VCS 对照覆盖同源全部 TRACE 与层次归一化后全部声明位的 settled 时间线；不把不同工具的内部事件顺序当作同一项对照。未做运行速度优化或性能测量。

正式发布与证据见 [M140](../validation/m140-sequence-antecedents/README.md)。
