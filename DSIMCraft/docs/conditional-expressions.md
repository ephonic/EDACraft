# 四态条件表达式

M132 修正 `condition ? yes : no` 的标量和多字四态合并，与 103 上 VCS W-2024.09 的独立探针对照。

- 条件确定为真/假时，选择相应分支，分支中的 X/Z 原样保留。
- 条件无法确定时，逐位合并两个分支：相同的已知 0/1 保留，其余为 X。此前相同 Z 位错误保留为 Z，现在得到 X。
- 宽向量各字使用同一规则，复用现有尺寸、符号扩展、赋值和事件处理。

例如 `1'bx ? 4'b10zz : 4'b10zz` 得到 `4'b10xx`；`1'b1 ? 4'b10zz : 4'b0000` 仍得到 `4'b10zz`。这不改变三目运算既有的类型推导规则，也不表示完整 SystemVerilog 类型系统已经对齐。

新增运行时 64 组条件/分支真值检查、多字独立数值检查，以及共享输入、未知动态位选与三目表达式组合回归。与 VCS 的同源探针对比包含 4/129 位的 64 组组合和完整稳定波形；验收见 [M132](../validation/m132-region-transport/README.md)。Active 区域显示可能观察到不同中间调度值，比较使用无竞争的延迟采样及稳定波形。

按照用户最新优先级，后续先补齐功能，正式速度复测与进一步结构优化后置。本次开发筛选的速度数字不作为最终版本的性能结论。
