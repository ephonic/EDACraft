# REPORT3 修复与 VCS 复核

输入为测试目录 `rtl-tests/complex/REPORT3.md`（2026-10-25）。远端指定路径未找到文件，使用本地同名报告及其原始 p27 探针；报告原文保留。

| 报告项 | 实际结论与处理 |
| --- | --- |
| 三元分支中的 `>>> / %` 退化为 unsigned | 原始 p27 在 VCS W-2024.09_Full64 和 dsim 输出相同。三元另一分支为 unsigned 时，类型上下文会影响分支计算；保留实现，加入原始六行输出及完整比特时间线回归。探针输出中的 `BUG` 是测试作者的文本，不是仿真器诊断。 |
| 字符串字面量与整数混合表达式 | 确认并修复。字面量同时保留文本和 unsigned packed 表示；数值上下文支持算术、移位、比较、混合拼接、复制、条件选择、赋值、函数实参及数值格式输出；常量求值和 `$bits` 支持相同表示。 |
| `assert ... else begin/end` 被拒绝 | 当前版本已支持。新增 immediate assertion 失败动作和 concurrent assertion 成功/失败动作的多语句块，用真实计数检查执行次数，与 VCS 均得到 `pass=2, fail=4`。 |

例如 `"AB"+1` 得到 `32'h4143`，`{"A",8'h42}` 得到 `16'h4142`。`X ? "AB" : "AC"` 在数值上下文按位合并为 `16'b010000010100001x`；赋给 `string` 时转换为 `"AB"`，与 VCS 一致。动态 string 的条件选择保留独立语义。

这不是完整 SystemVerilog 字符串支持：字符串端口、数组、形参/返回类型、string case、NBA、其余字符串方法、完整转义/NUL 规则仍有边界。REPORT3 的清单也不是完整 VCS 功能差距清单。没有修改门级 parser 或新增性能结论。
