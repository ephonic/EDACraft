# 运行期字符串重复

M225 支持字符串重复表达式 `{count{value}}` 的运行期整数计数，用于字符串赋值、
显示、比较、嵌套拼接、类方法、字符串队列和等待表达式。例如：

```systemverilog
int count = 3;
string word = "ab", result;
initial begin
  result = {count{word}}; // ababab
  $display("%s", {count{"xy"}});
end
```

计数与被重复值各求值一次；即使计数为零或负数，被重复值仍求值。
与 VCS 对照，零、负数或含 X/Z 的计数产生空串；宽整数计数和无符号计数保留类型。
空输入直接返回空串。普通常量 packed 重复继续按位处理，例如 `{2{4'ha}}` 为 `8'haa`，
不能把它改为逐字符拼接。字符串上下文也支持运行期 sized 整数的重复。

字符串可转换为 packed 变量、整数形参及整数函数返回值，按目标宽度截断或补零。
混合字符串拼接支持有宽度的整数操作数，拒绝无宽度数字字面量；字符串到 real 的
隐式转换尚未接入。普通 packed 数值的运行期重复仍未接入。

为限制分配，单次运行期字符串重复结果最多为 1,048,576 字节；超限明确报错。
这是 dsim 的实现边界，不是 VCS 的语言限制。实现先检查计数与大小，再按倍增方式
复制字符；状态采用已有字符串值存储，随 checkpoint 恢复。

尚未完成的反射语义：动态字符串重复的 `$bits` 当前按结果字节数计算，与 VCS
将该表达式视为 string 后报告 1 不同。带全局副作用的计数函数也尚未完整对齐
VCS 的常量函数检查。测试中的纯计数函数及被重复值的副作用已分别对照。
