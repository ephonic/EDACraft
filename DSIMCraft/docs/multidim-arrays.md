# 静态多维 unpacked 数组

支持 `logic/reg/bit`、内建整数、enum 和 packed struct/union 元素的静态多维变量数组。RTL parser 按源代码顺序保存维度；门级紧凑 parser 保持独立。每维上下界非负，可升序或降序，总元素数最多 1048576；packed 元素仍遵循既有降序范围限制。

```systemverilog
logic [7:0] cells[2:1][3:4];
initial begin
  foreach (cells[i,j]) cells[i][j] = i*16+j;
  cells[1][3] <= #2 cells[2][4];
end
```

常量下标直接绑定信号槽。动态下标依次求值一次，逐维检查完整位宽和 X/Z，再按固定步长计算元素偏移，时间复杂度为维数；不会在运行时扫描数组或遍历 AST。即使前一维无效，后续下标的副作用仍执行。越界/未知下标读 X、写忽略；两态元素的读取继续按两态规则转换。高位非零的宽下标不会截断后错误命中相邻元素。

多维元素接通 packed 选择、成员读写、符号/enum 类型、复合赋值与增减、函数 output 写回、delay/NBA、automatic 局部存储、敏感集合、依赖分区、波形和检查点回滚。`foreach` 按各维声明方向遍历，可省略索引；数组查询和 `inside {array}` 使用相同维度信息。automatic 数组继续采用现有非递归有界激活槽，不扩展到一般动态重入。

暂不支持动态/关联数组、队列、数组端口和形参、子数组运行时值/切片、整个数组赋值或声明初始化、负维度边界、数组 net。`$readmemh/b` 仍只支持单维数组。packed 聚合/成员/层次路径作为 foreach 目标的限制保持现状；聚合数组元素本身可按下标读写。

验收输入在 `tests/multidim_arrays/`。六组共同源覆盖三维方向、逐维副作用、宽/未知/越界下标、延迟取样、重叠 automatic 调用、查询/集合匹配、两态/符号/enum/packed 成员、真实双线程和预测失败回滚。VCS 默认不导出数组字，用同源 packed 观察信号逐位核验所有 660 位静态数组字的完整时间线；直接导出的 1544 位另行完整比较，不把数组字记为 VCS 直接导出位。证据见 `validation/m34-multidim-arrays/`。

静态变量数组的模块input/output和常量前缀子数组已于M39接通，逐维方向/尺寸约束及仍缺的net/复合类型数组端口见 [数组端口](array-ports.md)。上述历史数组端口缺口以此范围更新。

M40 范围更新：wire/tri 静态数组及 input/output/inout net 数组端口已接通，编译期按元素电气合并，支持反向驱动和静态子数组；此前文中一般 net 数组缺口以 [net 数组](net-arrays.md) 的当前边界为准。变量 inout/ref、动态数组、数组形参及整体数组值仍缺。

M41 范围更新：静态变量数组及常量前缀子数组的整体过程复制已接通，覆盖阻塞/NBA、net 源、宽字和 automatic 局部数组；当前类型规则、赋值内 delay 的实际 VCS 差异及仍缺范围见 [数组整体赋值](array-copy.md)。此前文中“整体复制仍缺”的描述以此范围更新，整体声明初始化、数组形参及动态数组仍缺。

M42范围更新：静态数组的动态前缀子数组过程读写/NBA已接通，含越界/未知索引与取样时点，见[数组复制](array-copy.md)；模块端口连接仍要求静态前缀，数组形参及动态容器尚缺。
