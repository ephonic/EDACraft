# 函数递归与互递归

M210 扩展编译式函数调用，支持模块、包和类方法的直接递归及互递归。调用环中每个 automatic 函数均保存、恢复自身的参数、返回值和自动局部存储；static 函数继续共享参数、返回值及静态局部变量，不将其改写为自动变量。静态函数中的显式 automatic 局部按调用保存和初始化。

类方法递归调用传递本次接收对象，支持不同对象之间递归、虚方法分派、默认参数和字符串返回。实参及接收对象保持单次求值。跨调用点复用函数代码时检查所捕获的递归目标，必要时重新生成绑定；静态函数重生成代码时复用原有存储和符号，静态声明初始化只执行一次。

自动局部初始化表达式可以递归调用函数。嵌套静态块重生成代码时重新绑定 automatic 初始表达式，同时保留静态初始化。递归调用使用原有运行时激活帧和对象堆，参与 checkpoint、预测提交及回滚，不增加未纳入快照的持久状态。

本批递归调用环仅支持标量 input 形参、标量或 void 返回；字符串和类句柄使用现有值表示。环中的 ref/const ref、output/inout、未打包数组形参/返回仍明确拒绝，递归 task、递归对象构造不在本批支持范围。每个递归目标的嵌套回调深度达到 1024 时报告运行时错误；这不是所有互递归栈帧合计上限。递归函数继续要求过程表达式上下文，未扩展为连续赋值或事件表达式。

七个同源模型覆盖嵌套调用环、自动帧、多对象、虚方法、默认值、字符串、静态存储、初始化及 checkpoint。验收记录见 [M210](../validation/m210-recursive-functions/README.md)。原版 Accellera UVM 2020.3.1 已越过此前的互递归首错，当前首错为 uvm_component.svh:1753 的字符串转义；这只表示编译推进，完整原版 UVM 仍未完成。

自动子程序模板的缓存键包含调用者的子程序帧，避免同一函数 AST 在不同自动任务实例中共享临时变量。既有 automatic_subroutines/parallel.sv 要求两条独立 TB 通路实际形成两个分区；本批同时修复此前稳定版存在的单分区退化。
