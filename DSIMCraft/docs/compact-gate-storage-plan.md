# 门级紧凑状态存储与合并写入后端

**合并写入后继已验收采用**，真实配对 CPU 减少 16.63%，证据见 [本批记录](../validation/m5-compact-drive/README.md)。第一版候选正确性通过，但真实五次配对 CPU 仅减少 0.76%，未达到采用门槛，已撤回。真实 RSS 减少 17.37%、反馈 CPU 减少 9.84% 的数据保留，不能替代真实 CPU 验收。原版 source SHA `7d50442262e323b6b421a17abbe215e9b8e3c1f8a7f35378ba619f4f5426d6c3` 为后续 A/B 基线。标量表达式两个候选均通过正确性、但未通过稳定性能验收，因此不能以它们的首轮数据宣称已接近 VCS。

真实网表独立驱动普查见 [原始数据](../validation/m5-scalar-logic/driver-census.json)。内部非端口 334,586 个 net 中，334,255 个只有一个叶输出驱动。现有 Signal 为 96 字节，包含完整 V、DriverValues 和 watch vector；四态表达式更短并未减少这些驱动表和信号状态的内存访问。优先评估其存储表示与访问路径，收益仍须实测。

候选已为内部单 bit net 新增独立的紧凑运行时槽，保存当前四态位平面、自己的驱动值/身份与原顺序 watch。端口、宽变量及一般 RTL 保持现有存储。若出现额外驱动或建立 alias，必须无事件地转入通用解析状态，保留首次 Z 驱动和此前全部驱动身份；直接 set 只改变解析值，随后相同 drive 必须能修复。编译期驱动普查只用于选择表示，不能省略运行期这些行为。

候选使用负 ID 区分槽类型，保存原信号的逻辑创建序号。`std::set<int>`/`std::map<int,V>` 的自然顺序会反转内部槽顺序；结构宽 copy、alias settle、过程分片提交必须按逻辑创建顺序发布变化。先收集所有 RHS 和解析结果，再逐信号发布，原有原子性、watch 顺序和 Active/NBA FIFO 都要保持。

检查点须深复制紧凑槽及通用回退状态；注册的模型 context 仍由原机制捕获。波形字典、初始 Z、ordered 的每次变化、settled、预测失败的输出隔离、多个 DUT、定时驱动以及保守并行输入端点都必须支持该 ID 类型。不能通过把内部网移出采集或只比最终输出掩盖事件差异。

通过编译宏仅为门级生成模型开启，普通 RTL 在关闭宏时的预处理代码/汇编须与已验收版本一致。RTL parser 与 gate parser 继续分离。先独立测试全四态、多驱动、alias、直接 set 修复、混合槽原子 copy、创建顺序、恢复/预测和延时/并行端点；再跑完整 gate/RTL 回归、有序流、实际生成回滚及 ASan/UBSan/TSan。

性能验收使用原始完整 Liberty/网表和 128 组黄金值，重新生成/编译两版，同核串行预热、交替测量 CPU/墙钟/RSS，保留 VCS 同轮数据和独立配对复测。真实收益未复现或反馈负载持续回退则不采用。此项不融合组合事件、不删除可观察 net，也不等同于实际 SDF 回标；带延迟路径与 timing check 的语义另行实现和验收。


本批候选源及实现见 [验证记录](../validation/m5-compact-nets/README.md)。每槽对象 48 字节、原 Signal 96 字节；真实拓扑中 334,255 个 net 入选，1,617 个仍走通用存储。本地/Linux 均 28/28，完整有序流、实际生成恢复、sanitizer、24 个生成模型的独立 eligibility 审计通过。移除紧凑宏分支后三份完整 runtime/waveform/parallel header 逐字恢复原版，8 种宏配置预处理/汇编通过。数值层的后续实际 SDF 进展另见 [精确合并暂存实现](../experiments/sdf_annotation/README.md)，没有改变尚无实际 CLI 回标的状态。

后继 [合并驱动写入候选](../validation/m5-compact-drive/README.md) 已在隔离源实现。固定连接、未晋级槽及相同/首次驱动身份时，一次槽访问完成驱动状态和变化发布，保留直接 set 修复、首次 Z 身份与全部唤醒；其余情况保留原解析。先以完整真实设计比较已验收后端/紧凑 A/合并 B/VCS，收益通过后才采用完整回归。

最终采用后的默认构建组合 28 项通过，门级生成 C++ 与实测 B 候选逐字一致；普通 RTL 关闭宏时的完整预处理/汇编仍相同。后续先补新后端 profile，再独立评价更密集的值布局与访问；不能从对象尺寸、旧指令百分比或合成用例推断新的真实收益。
