# Packed 聚合作为关联键

M197 允许 packed struct、packed union 及其类型别名作为关联数组键。键存储沿用完整位宽整数表示；按声明符号进行遍历排序，并保留规范聚合身份供字段访问和每一维复制检查。门级 parser 不受影响。

foreach 隐式索引和 find_index 等 locator 返回队列携带字段信息，支持嵌套成员、类属性、类类型参数及模块克隆。游标可接收同宽整数或 packed 变量；元素按值传递允许同宽 packed 聚合和位向量转换。整张关联映射复制要求键的聚合身份相同，类型别名保留同一身份；不能把不同 struct 或同宽 bit 向量的映射直接混用。

新增模型覆盖 160 位地址范围、signed 65 位结构体、packed union、129 位嵌套字段、33/65/129 位特化、多维类属性以及预测回滚。类型元数据只在语义分析期间绑定；重复解析、失败清理和特化不复用旧字段指针。

unpacked struct 键仍拒绝；已有 ref 绑定继续要求 dsim 的精确类型规则。与 VCS 的接收差异和最终发布结果见 [M197 验收](../validation/m197-packed-keys/README.md)。原版公开 UVM 已越过地址范围键，仍阻塞于 string 队列方法，不能据此认为完整 UVM 可用。
