# 枚举初始化的位宽与符号

M196 修复无符号枚举对负数常量的过度拒绝。32 位及更宽的无符号基类型可接收无尺寸 `-1`，例如公开 UVM 的 `typedef enum bit[31:0] {ALL=-1} coverage_e`；先按表达式符号扩展，再转换为基类型的无符号位串。32、33、65、129 位结果分别为对应宽度的全一。枚举标签和变量保留基类型的符号、位宽及枚举身份。

窄于表达式自然宽度的无符号基类型仍不能接收无尺寸负数，例如 `bit[7:0]` 和 `bit[30:0]` 的 `A=-1`；同宽显式 `A=-8'sd1` 可接收。过宽的显式尺寸表达式、真正的数值溢出、重复标签、两态 X/Z、全一之后的隐式递增仍拒绝。实数初始化在范围判断前明确拒绝为非整型常量。

独立 VCS W-2024.09 的 29 个探针覆盖这些边界，dsim 接收/拒绝结果一致。三份同源执行模型覆盖包内枚举及别名、类属性/形参/返回值、方法顺序、无符号零扩展、32/65/129 位参数化实例及隐式递增，TRACE 与 VCS 一致。执行与发布的最终结果见 [验收记录](../validation/m196-enum-initializers/README.md)。

原版 UVM 2020.3.1 已越过 `UVM_CVR_ALL=-1`，下一处阻塞是 `uvm_reg_map_addr_range` packed struct 作为关联数组键，完整 UVM 仍未编译运行。该修复不代表约束、覆盖率、virtual interface 等能力完整。
