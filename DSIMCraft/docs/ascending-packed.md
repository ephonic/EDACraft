# 升序 packed 范围

RTL 支持 `logic [0:7]`、非零或负标号范围（例如 `[4:19]`、`[-8:7]`），以及 typedef、packed struct 字段、固定数组元素、模块端口和子程序参数。左端仍是最高有效位；整字连接和赋值按有效位顺序对应。

普通范围选择必须与声明方向一致；`+:` 和 `-:` 的方向按标号增减解释，与声明方向分开。动态下标先执行全宽四态/范围检查，再转换成物理位偏移；部分越界选择保留有效部分，越界读为 X、写忽略。下标副作用只求值一次；延迟 NBA 保存当时目标。静态选择仍在编译期折叠，用于驱动冲突和组合敏感性分析。

标准文本 VCD 保留声明范围及方向。未改变波形编码格式。范围上限仍为 1,048,576 位；完整 SystemVerilog 类型、任意多维组合和所有层次写入不在本批支持声明内。已有多维选择的完整维度越界规则保持原实现，与单维裁剪行为分开。

永久回归 `tests/ascending_packed` 使用独立 Python 标号/位序 oracle，并覆盖三后端、回滚和实际双分区；实际 VCS 同源对照及验收证据见 `validation/m90-ascending-packed`。

已知对照边界：VCS W-2024.09 对本组两条极端有符号 64 位下标（INT64_MIN/MAX）读选择返回 `0101x`，dsim 按原始全宽范围返回 `xxxxx`。这是先前索引测试已记录的差异，本批保留并公开完整两条输出差异，不声明这两条对齐；所有波形仍完整比较，不裁剪时间区间。
