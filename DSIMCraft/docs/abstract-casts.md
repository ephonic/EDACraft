# 抽象类、纯虚方法与动态转换

M152 增加 module/package 内的 `virtual class`，以及无方法体的 `pure virtual function/task` 原型。普通派生类必须实现全部继承的纯虚方法，即使没有实例化也检查；虚类可以继续保留纯虚方法。直接构造虚类会拒绝，但具体派生类的构造仍会执行虚基类构造器和属性初始化。纯虚方法的签名、默认/命名参数、协变类返回及延时任务复用既有类执行链路，parser 克隆保留声明标志并重新绑定类身份。

`$cast(destination, source)` 支持已实现的 singular 类句柄、integral/enum 变量、固定数组元素、类属性及匹配的 string。函数形式返回 32 位 int：成功赋值并返回 1，失败保留目标并返回 0。不相容的受支持标量类型同样返回 0。任务形式失败报运行时错误并停止；`void'($cast(...))` 则丢弃函数结果。参数个数、非变量目标和整个 unpacked 数组会拒绝。

类转换先检查静态类关系，再检查实际对象及祖先类型；支持向下转换、向上转换、相容的 null 和转换后的虚方法分派。静态无关的类即使源句柄为 null 也返回 0，字面 null 可以赋给任意支持的类句柄。对象类型信息及目标句柄的修改参与 checkpoint/预测事务。

普通 integral 转换按目标宽度保存，并保留源的有符号扩展；枚举先对原源值与枚举成员作四态精确比较，成功才保存。不会先截断高位来使非法值变为合法值。枚举的 X/Z 成员和超过 64 位的值通过相同链路处理。目标选择表达式及源表达式各求值一次；当前先求值目标选择再求源。

实测 VCS W-2024.09 仍有这些对照差异，未计为完整对齐：

- 类属性目标的接收者带副作用时，VCS 成功转换求值两次、失败一次，并先求源；dsim 各求值一次。
- 同源目标为枚举数组元素时，VCS 接受 `32'h1fc` 到仅有 2/fc 两个成员的八位枚举并截断；dsim 保留严格的原值成员检查。失败时目标选择的副作用也可能不同。
- 同源 129 位枚举的 `$cast` 成功后，VCS 观察值为全 1，dsim 为声明的 `129'h100000000000000000000000000000001`；保留原始输入和两端波形，不据此推广到所有宽枚举。
- `super` 直接调用无实现的纯虚方法，dsim 编译期拒绝，VCS 在本轮两个输入中接受。

对象堆仍通过显式 SV 观察变量输出波形。范围筛选及独立编码/压缩/写盘线程继续适用，见[波形说明](waveform-format.md)。参数化/编译单元类、动态对象容器、访问限定符/extern、约束随机、mailbox/virtual interface/clocking/coverage 和完整 UVM 仍待补齐。
