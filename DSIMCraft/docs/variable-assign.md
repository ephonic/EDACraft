# 显式变量连续赋值

模块级 `assign` 支持 logic/reg/bit、整数、enum、packed 聚合及宽向量变量。可写整体变量、静态位段、静态 unpacked 数组字、packed 成员，以及变量与 net 混合拼接。RHS 按整个目标宽度取样一次，然后执行普通变量转换或 net 驱动；部分写入保留其他位。枚举仍执行已有的名义类型检查。声明初始化保持过程写入语义。

变量目标支持单值常量 delay，包括零延迟。非零 delay 复用已有连续驱动的惯性事件队列，支持脉冲取消、X/Z、时间轮、检查点和失败预测回放。net/变量的目标列表在绑定时拆分一次，投递时不再创建或拆分列表；未使用延迟变量的程序不启用新增 runtime 宏。X/Z 在事件投递给两态变量时转为零，取消判断仍保留原始四态 RHS；实际 VCS 的 X→Z 短间隔探针确认了这一行为。

每个变量位只能被一个连续过程或端口驱动，并禁止叠加过程赋值和声明初始化。检查使用静态区间扫描，不再逐对比较连续变量驱动，复杂度为 O(W log W)，W 是该变量的写区间数；已有 always_comb/latch/ff 专项检查不因此获得同样复杂度保证。过程动态 packed 成员选择按该成员的最长静态前缀登记写范围，因此可与其他成员的连续赋值共存。动态数组写仍覆盖全部可能数组字。

限制：连续赋值的动态左值、运行时 delay、变量目标的多值 delay、一般非默认强度和完整事件区域尚未支持。数组端口、ref、命名类型模块端口等仍缺。重复变量拼接存在一个明确差异：已测无延迟 `assign {v,v}=8'h96`，dsim 最终为 6，VCS W-2024.09 为 9；带延迟的同类赋值双方为 6。本轮保留双方原始探针，不宣称这个边界已对齐，也不改变上一轮模块输出连接的右侧覆盖行为。M35/M36 已记录的历史差异仍保留。

共同源覆盖 signed 扩展/截断、两态转换、130 位向量、枚举方法、packed 成员、静态多维数组、函数副作用、多层模块输出、NBA、混合拼接、延迟和真实双分区。六模型在三后端、两波形模式、VCD/DWF 间核对，另验证挂起事件期间预测回滚和独立区间冲突预期。实际 VCS、Linux 和 sanitizer 证据见 [M38](../validation/m38-variable-assign/README.md)。这些是定向功能验证，本轮没有重新测量 dsim/VCS 仿真速度。

后续M39已支持静态变量数组input/output及静态子数组，见 [数组端口](array-ports.md)；不包含整数组assign或数组形参。
