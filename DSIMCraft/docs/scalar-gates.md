# 门级标量四态求值候选

状态：两版均通过正确性，但性能复测未通过，均未采用；生产源已恢复。第一版真实收益未在五次配对中复现，详见 [完整结果](../validation/m5-scalar-gates/README.md)；后继的存储投影与位平面编码见 [证明](../validation/m5-scalar-logic/proof.md) 和 [完整性能记录](../validation/m5-scalar-logic/README.md)。尚不宣称新增默认性能收益。

独立门级 parser 将宽结构连接展开为位级 net，安装器为每个 pin 建立 1 位运行时 signal。Liberty function 中的常量、pin 与 ff/latch 的两个状态变量因此都只需 0/1/X/Z，而一般 RTL 的 1–64 位运算继续使用 V。候选用 `uint8_t` 保存表达式中间结果，编码与 `V::bit(0)` 一致：0/1/X/Z = 0/1/2/3。

固定反相将 0/1/X/Z 映射为 1/0/X/X；AND/OR 采用四态控制值规则，XOR 在任一未知时为 X。没有二态消除规则，`X ^ X` 仍是 X。three_state 在 disabled=0 时保留输入（包括 Z），disabled=1 时为 Z，disabled=X/Z 时为 X，与现有 Liberty 专用规则一致。两个状态变量各自保留，不推断互补；状态 Z 在进入采样逻辑时归一化为 X。

`get_scalar` 直接读取低位，消除宽度及两个 64 位掩码的中间传递。输出转换回 1 位 V，进入完全不变的 drive/多驱动/alias/set/通知与唤醒路径。采样入口接受字节后调用原 capture 状态算法，通用 V 入口先执行原 logic 归一化再调用相同算法；不改变 NBA 提交、待提交值和冲突属性。未增加状态字段，检查点复制与并行 ownership 保持。大结构 copy 继续原子 `drive_copies` 路径。

本候选不融合单元、缓存输入或删除事件，不重排 pin、输出、process、watch 或安装过程；敏感列表仍由相同名称引用集合计算。只更换模型求值函数的标量运算和采样入口。完整有序事件而非仅 settled 输出决定是否等价。SDF 实际回标仍未实现，不把零延迟证明推广为路径/脉冲变换。

验证包括独立四态真值表与复合函数、100k 采样边界、实际 gate/VCS、原真实网表的 128 个完整 golden、有序波形、实际生成回滚模型、ASan/UBSan 与并行线程检查。性能须同输入、同编译器 O2、同 CPU，保存预热及交替重复样本；真实设计收益须复现，普通 RTL 用作保护负载。

第二版配对复测真实 CPU 13.20→14.48s、100k ff 5.37→6.90s；不能使用首轮 17.84→11.77s 宣称加速或达到 VCS 性能。上文四态 rank 描述第一版；第二版组合域为 0/1/Z/X 位平面，采样域为 0/1/X，均只是实验。下一步为 [紧凑信号/驱动存储计划](compact-gate-storage-plan.md)，尚未实现。
