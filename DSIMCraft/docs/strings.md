# 动态字符串与枚举名称

M81 补齐 RTL 报告 B9 原始 `t11_enumname.sv`。`state.name` 和 `state.name()` 返回成员声明名称；按完整基类型宽度做四态精确匹配，支持 X/Z 标签，未命中返回空串。名称不按寄存器宽度截断，83 字节名称与 130 位枚举有同源 VCS 用例。

支持模块和过程块的 `string`、`typedef string` 别名、字符串文字、声明初始化、整变量阻塞赋值与复制、字符串拼接、比较及纯字符串条件选择。字符串默认值是空串。支持 task/function 的字符串局部变量，包括 static/automatic 生命周期、重叠调用、延迟和内部延迟赋值的 RHS 快照。

M95 补齐标量字符串子程序签名：ANSI/经典形参、`typedef string`、`input/output/inout`、automatic `ref/const ref`、默认/命名/省略实参、`function string` 及 `return`/函数名赋值。字符串返回值可直接作为方法 receiver 或嵌套调用实参；既有 automatic 直接递归也支持标量字符串输入和返回值。static 返回变量保留值，automatic 返回变量每次从空串初始化。输出形参在返回时复制；ref 在整个任务延迟期间访问原变量，const ref 的写入和转交可写 ref 仍拒绝。普通变量的 ref 绑定要求两边都是字符串，不能因内部存储槽宽度相同而绑定到 1 位 logic。函数体仍遵循既有零时阻塞语句范围，函数中的系统任务语句暂不支持。数值到字符串的入口和返回转换沿用已有按字节规则，M100 已接通显式整数解析和格式化方法，见[整数转换](string-integer.md)。

字符串函数返回值的变化可触发表达式事件；依赖、分区、自动激活和预测回滚沿用原调度器。新用例覆盖自动任务重叠、延迟 RHS 捕获、同一字符串值不重复触发事件和实际双分区。验收见 [M95](../validation/m95-string-subroutines/README.md)。

| 方法/表达式 | 结果与规则 |
| --- | --- |
| `len()` | signed 32 位字符数，以字节计数 |
| `getc(i)` | unsigned 8 位字符，负数或越界返回零；实参先按 signed int 参数转换，X/Z 位清零 |
| `substr(i,j)` | 包含两个端点；负数、逆序、越界或含 X/Z 的索引返回空串 |
| `toupper()/tolower()` | 返回新字符串，转换 ASCII 字母 |
| `compare()/icompare()` | signed 32 位；首个不同字节的差，前缀关系返回 ±1；后者忽略 ASCII 大小写，与本次 VCS 探针一致 |
| `== != === !== < <= > >=` | 字符串间按字节比较；两个常量字符串文字按 packed 无符号数比较，避免将 `"z" < "aa"` 错当词典序 |
| 条件选择 | 条件必须为整数；动态字符串分支遇 X/Z 条件得到空串；两个字面量先按 packed 位合并再按上下文转换；含副作用的字符串分支暂拒绝 |
| `%s`、`%0s`、数字字段宽度 | 用于已有 display/write/severity 任务；保留字符串开头的零，宽度只补空格 |

运行时按需启用不可变、共享所有权的字符串值。字符串信号、延迟捕获、自动激活和检查点沿用既有 V/Sim/Process 复制，不使用外部全局字符串表。未使用字符串的模型不增加字符串值字段。字符串变化和方法读取参与依赖及分区。IR 对字符串标记 `string: true`、`width: null`，内部存储槽号不代表一个 packed 位。

动态字符串不导出为伪造的比特波形；本次 VCS `$dumpvars` 同样不导出字符串。验收同时检查字符串输出、自检、数值观测和全部公开数值位的完整时间线；三后端和回滚则比较全部原生 ordered VCD 流。没有修改 DWF。

VCS W-2024.09_Full64 的实测差异：`always_comb length=source.len()` 在字符串后续变化时没有重新求值，长度留为零；dsim 按字符串依赖重新求值。原始失败输入与日志单独保留，未计入共享对齐。共享时序模型使用显式 `always @(source)`，仍完整核验延迟 RHS、变化触发和复制。`implicit.sv` 保留为原生回归及失败预测用例。

限制：不支持字符串模块端口、一般动态数组和类成员固定数组（M230 已支持[固定字符串数组及形参](array-streams.md)，queue 另见对应专题）、层次 ref 实参、实数转换方法、NBA、连续赋值、复合赋值、字符串与整数的完整隐式转换、字符串参数常量求值及带副作用的条件分支。只接受原有字符串转义集合（换行、制表、反斜杠、双引号），未实现完整转义和 NUL 规则。M98 已支持精确字符串 case 和字符下标阻塞写，M100 已支持 putc 及八种整数转换；它们不再属于限制。字符串不能直接作布尔条件；M93 已补齐字面量在算术、移位、比较、混合拼接、条件选择、整数赋值/实参及数值显示中的 packed 表示，同时支持常量求值和 `$bits`；整数赋给 string 按字节转换。未支持路径仍明确拒绝，详见 [REPORT3 复核](report3-review.md)。RTL 与门级 parser 保持独立，不等同于完整 SystemVerilog/VCS 支持。

同源探针和验收记录见 [M81](../validation/m81-strings/README.md)。
