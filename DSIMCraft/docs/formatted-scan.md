# 格式化输入扫描

M104 接入 `$sscanf(source, format, targets...)` 和 `$fscanf(fd, format, targets...)`。两者返回成功赋值的转换数；第一次赋值之前遇到输入结束返回 -1，普通不匹配返回 0。已匹配的目标写回，未匹配的目标保留原值。被 `*` 抑制的转换不计数，也不占目标参数。

支持动态 source/format、字面量、格式中的空白、`%%`、十进制字段宽度，以及以下转换（大小写均可）：

| 转换 | 行为 |
| --- | --- |
| `%d` | 有符号十进制整数、下划线，单个 X/Z/? |
| `%h/%x/%o/%b` | 对应进制，包含下划线、X/Z/?；不接受符号前缀 |
| `%s` | 跳过前导空白，读取非空白字符；写回 string 或 packed 变量 |
| `%c` | 读取一个原始字节，保留空白；字段宽度按 VCS 忽略 |

整数按目标位宽截断，支持宽值、四态以及二态目标的常规强制转换。`0x12` 在 `%h` 中的 x 是四态数字，不当作 C 语言进制前缀。字符串/packed 输入忽略 packed 的前导零字节，首个内部 NUL 结束扫描；文件通过 `%c` 可以读取 NUL。字段宽度上限 1048576。无转换格式遇到空 packed 输入返回 0，遇到空 string 输入返回 -1，按 VCS 实测区分。

目标必须是可写变量，支持元素、片选、拼接及 automatic/ref 写回。调用入口先从左到右求值输入、格式和所有目标，完成扫描后对每个成功转换再次求值目标地址并写回。例如 `$sscanf("7 nope","%d%d",a[i++],a[i++])` 在 i=0 时最终 i=3，写入 a[2]；第二目标不写回。`const ref`、net 和 enum 目标明确拒绝。

文件扫描复用 [事务文件 I/O](file-io.md) 的游标、EOF 和回推状态，保留第一个未匹配字符。预测拒绝时恢复，接受时保留；对外文件写入仍遵循既有事务规则。文件副作用依赖通过子程序、初始化和目标表达式传播到调度分区。单独使用 sscanf 不启用文件缓存。

格式在消费输入前完整校验。当前要求非抑制转换与目标数相同，数值转换要求 integral 目标；不支持实数、`%p/%u/%z/%v`、扫描集合和完整标准格式族，未支持格式明确报错。交互 stdin、外部进程同步及完整 OS 错误接口仍有缺口。不能据此宣称完整 VCS 兼容，也没有新增性能测量。
