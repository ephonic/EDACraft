# 非阻塞赋值内部事件控制

支持 `q <= @(event) rhs` 和 `q <= repeat(count) @(event) rhs`。发起进程立即继续；每笔更新独立保存 RHS、目标地址及剩余次数，事件满足后进入 NBA 队列。支持普通信号/四态边沿、表达式/选择、事件列表、静态命名事件、iff 与已有无外部副作用 automatic 事件函数。automatic task 可发起对静态变量的更新，RHS/次数在调用期间取样，任务返回不会丢失已挂起的更新。

真实 VCS 探针显示，非阻塞重复事件赋值先求 RHS，再求次数；动态目标在发起时求值。零/负/X 次数直接排入 NBA，仍然晚于发起过程和 `#0`。阻塞形式的目标求值时间及次数/RHS 顺序不同，见 [阻塞内部事件赋值](intra-event-assignments.md)。

运行时使用编译期固定的订阅表和按赋值点保存的待交付记录；源变化按 Active FIFO 合并判断事件/iff，不轮询，不在仿真期间增加进程或结构。每笔更新拥有独立基线/计数/取样值/目标，晚发起的记录不能消费早先已排队的发生。记录、基线、Active/NBA 队列随 Sim 检查点复制，支持失败预测恢复。宏仅在设计使用该功能时启用；门级 parser 保持独立。

automatic 任务变量不得用作非阻塞目标或此类赋值的事件源/iff 条件，真实 VCS 也拒绝后者（IEEE 1800-2017 §13.3.1）。整 unpacked 数组、隐式内部事件、事件对象句柄/数组及原有有副作用事件函数限制继续保留。原始探针还保留两项未计为对齐的结果：动态拼接目标中调用静态索引函数时，VCS 与 dsim 输出不同；另一项同时包含索引/次数函数的源触发该版 VCS 内部编译错误。共同模型的动态拼接使用整数索引，函数索引的上述组合仍有差异。

验收证据见 [M50](../validation/m50-event-nba/README.md)。本批补功能与语义覆盖，没有新的性能测量，不宣称完整 SV/VCS 事件区域或全部验证功能。
