# 静态变量数组端口

模块 input/output 可以使用静态 unpacked 变量数组，连接整数组或常量下标选择的子数组。支持多个 unpacked 维度、参数/generate 展开、非零下界和不同声明方向，以及受支持的 integral/bit/logic 元素。每维大小和剩余维度数必须一致，元素位宽必须相同；同宽的两态/四态转换在目标变量写入时执行。当前数组下界沿用存储器实现限制，必须非负。

```systemverilog
module child(input logic[7:0] a[3:2],output logic[7:0] q[5:6]);
  assign q[5]=a[3]+1, q[6]=a[2]+2;
endmodule
module top;
  logic[7:0] a[0:1],q[9:8];
  child u(a,q); // a[0]→a[3]，q[5]→q[9]
endmodule
```

端口按每一维的声明顺序对应，而不是按相同数值下标连接。编译时将绑定展开为逐元素静态适配过程，沿用已有敏感依赖和变量存储；一个元素变化只唤醒对应适配过程，没有运行时数组类型分派。输出数组或子数组与过程赋值/另一个输出的重叠受既有变量写入检查约束，不同元素可以分别驱动。IR 的数组端口 signal_id 为 null，array_elements 给出每个 formal/actual 信号ID对应，binding 为 array_adapter。

未连接的四态数组输入保持X，全部两态输入保持0，实际VCS探针已核验。还修复了带delay的宽数组元素被误作标量目标的问题：完整unpacked元素保留packed向量属性，只有packed位选才按标量处理。

范围限制：仅静态变量数组input/output。wire/tri数组、变量inout/ref、动态前缀、数组slice/拼接/赋值模式、整数组表达式/过程复制、数组端口默认值、enum/packed聚合数组端口、命名复合模块类型和数组形参尚未支持。输入端口按单向变量适配处理，没有增加可内部反向驱动的net数组连接语义。动态过程写的冲突分析仍可能保守覆盖整块存储器；本轮没有细化这一既有限制。根/断开标量输入和M35/M36/M38历史差异保持原边界。

五组共同源覆盖相反方向、静态多维子数组、层次、130位/两态转换、未知值、delay/NBA、双分区及回滚，另有未连接输入、尺寸/元素位宽拒绝和输出子数组的原始VCS探针。完整波形逐位核对，并以同源packed观察信号覆盖VCS未导出的每个数组字，不把未核验数组计入一致数。证据见 [M39](../validation/m39-array-ports/README.md)。本轮没有新仿真速度测量。

M40 范围更新：wire/tri 静态数组及 input/output/inout net 数组端口已接通，编译期按元素电气合并，支持反向驱动和静态子数组；此前文中一般 net 数组缺口以 [net 数组](net-arrays.md) 的当前边界为准。变量 inout/ref、动态数组、数组形参及整体数组值仍缺。

M41 范围更新：静态变量数组及常量前缀子数组的整体过程复制已接通，覆盖阻塞/NBA、net 源、宽字和 automatic 局部数组；当前类型规则、赋值内 delay 的实际 VCS 差异及仍缺范围见 [数组整体赋值](array-copy.md)。此前文中“整体复制仍缺”的描述以此范围更新，整体声明初始化、数组形参及动态数组仍缺。

M42范围更新：静态数组的动态前缀子数组过程读写/NBA已接通，含越界/未知索引与取样时点，见[数组复制](array-copy.md)；模块端口连接仍要求静态前缀，数组形参及动态容器尚缺。
