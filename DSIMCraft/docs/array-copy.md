# unpacked 静态数组与动态子数组过程赋值

M71追加：[固定数组声明初始化](fixed-initializers.md)已接入固定数组/子数组复制；下文M41/M42的“声明初始化未支持”描述保留当时边界。M72追加的[多维packed元素与端口](frontend-compatibility.md)保持独立RTL/gate parser。

支持静态 unpacked 变量数组的整数组及常量/动态索引前缀子数组过程复制，包括阻塞赋值、NBA、延迟 NBA、always_comb/always_ff，以及函数和非递归 automatic 任务中的局部数组。源可以是变量或 wire/tri 数组；过程目标必须为变量。RTL 与紧凑门级 parser 继续分开，沿用现有数组 AST、信号槽和调度内核。

```systemverilog
logic [7:0] a[3:2][7:6], b[0:1][4:5], row[0:1];
initial begin
  a[3][7]=1; a[3][6]=2; a[2][7]=3; a[2][6]=4;
  b=a;           // b[0][4]←a[3][7]，逐维按声明顺序对应
  row=a[3];      // 常量前缀子数组
  row=a[i];      // 动态前缀；索引求值一次
  a[i]<=#2 row;  // 入口捕获目标子数组地址和源值
  row<=#2 a[2];  // 在入口取样全部源元素，2个时间单位后交付
end
```

剩余 unpacked 秩和每维大小必须相同，元素位宽、signed 属性及 enum 身份必须兼容。支持同一 enum、宽 integral 元素及与 packed struct/union 等宽同符号的 integral 复制。按实际 VCS 行为允许同宽同符号两态/四态转换，由目标存储执行逐位 X/Z 到0转换；这比严格按 IEEE 1800-2017 6.22.2 的 state 等价条件检查更宽松，不将它描述为严格类型等价验证。

编译器生成声明顺序的信号 ID 表，以及两遍 C++ 循环：先取样全部源字，再写入或排入 NBA。自复制、共享存储及源在交付前变化不会导致逐字混用新旧数据。每条过程赋值复用自己的缓冲，不为每次执行重新创建进程缓冲；零时间函数的局部缓冲在函数调用时创建。读写集合记录每个具体元素，进入组合敏感集合、专用 always 写入检查和并行图。automatic 变量上的 NBA 继续禁止。

阻塞赋值内 delay 在 dsim 中先保存全部源字，然后挂起进程，恢复时写目标。保存向量随进程对象进入检查点，覆盖等待期间的失败预测回放。**VCS W-2024.09 对共同原始探针中的整数组阻塞赋值内 delay 没有等待**：`b<=#2 a; c=#3 a; #1 $display(...)` 在 VCS 于1ns打印、dsim于4ns打印；只添加 packed 观察信号的变体仍有同样差异。这项没有宣称对齐，也没有忽略 dsim 中的 delay 来迎合该结果。共同源对照采用受支持的延迟 NBA及显式 delay 后复制；原始探针和两个 dsim 独立预期用例另外保留。

范围限制：支持整数组及常量/动态前缀 subarray；不包含 array slice、数组条件表达式/拼接/赋值模式、整个数组声明初始化、数组连续赋值、数组形参或动态/关联数组和队列。原有非负 unpacked 下界、降序 packed 范围及总元素数限制不变。变量 inout/ref、一般层次数组表达式和完整事件区域等仍缺。

验收入口为 `ctest --test-dir build -R '^rtl_array_copy$' --output-on-failure`。共同源六例覆盖多维方向、宽字/类型/net 源、函数与 automatic 任务、组合/时钟过程、延迟 NBA重叠、两独立分区；另外两个 native 用例验证阻塞赋值内 delay、宽字取样、automatic 挂起隔离和真双分区。串行、时间轮、双线程、VCD/DWF、检查点及 VCS 逐位结果见 [M41](../validation/m41-array-copy/README.md)。未做新的仿真速度测量。

M42补入动态前缀：`row=a[i]`、`a[i][j]=row`、`a[i]<=#delay b[j]`。每个前缀索引先求值一次，再用完整位宽/四态逐维检查；任一无效，整个子数组读取返回源元素默认值（四态X、两态0），目标不写入；后续索引表达式的副作用仍执行。通过共享原存储器ID表及声明顺序偏移表寻址，先完整取样源再写目标；静态有效前缀保留原生成路径。动态源读集合保守包含整个存储器及索引，动态目标写集合覆盖所有候选字，接入组合敏感、单驱动检查、并行分区与回放。动态目标与被读取数组重叠的专用always块仍受既有partial-write限制；模块数组端口的动态连接没有随之开放。

NBA在执行赋值时取样源和目标地址，之后索引变量改变不影响交付；阻塞赋值内delay先取样源，等待后才求目标地址。源、目标及delay索引函数各执行一次。IEEE 1800-2017 10.4.1/10.4.2未规定无delay阻塞或NBA左右操作数之间的相对求值顺序；dsim选择源先于目标。原始共享计数器探针VCS阻塞取目标后取源，因此计数1与dsim的10不同，这是顺序未指定的可观察差别。更需注意VCS W-2024.09在本批数组NBA探针中逐元素重复求索引/delay，两字无delay计数1010、带delay210210；dsim各一次，分别10/210。没有把这些原始差异计入功能对齐PASS。赋值内delay本身的函数调用此前被parser误拒绝，M42已修复并新增三轮语义分析/清理检查。

M42验收入口为 `ctest --test-dir build -R '^rtl_dynamic_array_copy$' --output-on-failure`；四个共同源覆盖多维方向/net源/函数内数组、130位数据和高位未知或越界索引、两态默认值、组合/时钟过程、NBA地址和源值取样及两独立域。另两例native覆盖阻塞内部delay晚求目标地址、automatic挂起隔离与NBA索引/delay单次求值。验收结果及原始差异见 [M42](../validation/m42-dynamic-array-copy/README.md)。M41记录保留当时状态，M42关闭其动态前缀缺口；array slice/模式/初始化/连续赋值/形参和动态容器仍缺。没有新速度测量。
