# 类参数列表

M166 补齐类参数列表中的连续省略声明，例如公开 UVM 的
`class uvm_pool #(type KEY=int, T=uvm_void)`。省略项继承前一声明的参数种类；
值参数同时继承显式数据类型、符号性和 packed 范围。每个类型参数独立绑定，
特化 `U` 不会覆盖 `T`。支持以省略 `parameter` 的值参数开头、命名数据类型、
前项依赖、类型/值分组切换，以及没有默认值的必填值参数。

必填参数必须由实际特化提供，包括命名空实参也不能代替必填值；不会用零作为
隐含默认值。覆盖实参在调用方作用域求值，未覆盖的默认值依次在类声明作用域
绑定。保持既有特化规范化、模块实例隔离、继承及 extern 方法绑定。
参数 packed 范围拒绝运行时变量作为边界。

逗号后的 `pkg::type argument` 现在也识别为新的形参声明，保留既有方向继承规则。
例如前项为 `ref` 时，省略方向的下一项仍为 `ref`，传入字面量仍应拒绝。

依据 [IEEE 1800-2017 §6.20、§8.25 和 Annex A](https://fpga.mit.edu/6205/_static/F25/documentation/1800-2017.pdf)。
本批限于既有 integral/class 类型系统：不代表支持所有参数数据类型、类体参数规则或
完整参数化类型语法。M167 已补齐[逗号后的参数化类形参](parameterized-formals.md)，
公开库当前仍在 real 类型处阻塞；编译单元类、约束随机、IPC、virtual interface/clocking、coverage 等仍需补齐。

`tests/class_parameter_lists` 验证默认值/必填值、二态/符号性/65位数据、129位实例克隆、
类型规范化、继承虚调用与 extern、作用域限定形参、真实双分区、预测回滚/提交及
用户范围的异步压缩波形。公开 UVM 库保持原样复测，预处理通过不计作原生运行通过。
