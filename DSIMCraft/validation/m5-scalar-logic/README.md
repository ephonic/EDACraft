# 存储投影与组合位平面候选

**未采用，已逐字恢复已验收生产源。** 不宣称新性能收益。第一版正确但真实收益未复现，见 [第一版完整证据](../m5-scalar-gates/README.md)；本版继续减少采样归一化和组合 X/Z 编码成本。

组合 pin 直接打包 V 位平面，0/1/Z/X=0/1/2/3；布尔运算用位运算/已知零一谓词，输出还原 V 后进入原 drive。ff/latch 的 Boolean 采样使用 0/1/X=0/1/2，在读取时归一化 Z 并调用已归一化采样入口。投影与支持的 Boolean 运算可交换，但不用于组合输出或 three_state。两个状态变量仍独立，原 capture 算法逐字保留。完整 [证明](proof.md) 包含各入口的前提。

没有新增状态字段或改变安装器、drive/set、alias、watch/唤醒、固定敏感列表及 Active/NBA 顺序。RTL 与 gate parser 保持分开，普通 RTL 向量运算保持。SDF parser/绑定、并行与波形编码器未改变；本批继续覆盖它们的核心和回滚回归，不把零延迟优化称为实际 SDF 回标。

## 性能与决定

主实验每组一次预热、三次旋转，CPU 秒中位数：

| 负载 | 已验收原版 | 候选 | VCS |
|---|---:|---:|---:|
| 真实 300,909 cell | 17.84 | 11.77 | 12.15 |
| 100k ff 反馈 | 7.66 | 8.35 | 6.83 |
| RTL clocked | 2.75 | 2.95 | 2.96 |
| RTL fanout | 2.76 | 2.96 | 3.68 |
| RTL arithmetic | 0.49 | 0.50 | 0.47 |

真实原版三次为 11.87/18.85/17.84s，候选 11.75/11.77/17.85s；本轮大幅波动，不能把首轮约 34% 当稳定收益，也不能称候选已与 VCS 持平。额外核对三类普通 RTL 二进制的 `.text` 与 `.rodata`，均逐字相同；抽取字节和输入二进制 SHA 随证据保留。它们的首轮时间差不能归因于生成的机器码变化。

同二进制、同 CPU 的独立五次交替配对中位数（本轮没有 VCS，不混用上轮分母）：

| 负载 | 已验收原版 | 候选 | 变化 |
|---|---:|---:|---:|
| 真实设计 | 13.20 | 14.48 | 增加 9.70% |
| 100k ff | 5.37 | 6.90 | 增加 28.49% |
| RTL fanout | 2.71 | 2.72 | 增加 0.37% |

真实五对中四对变慢，反馈五对均慢；不是可复现加速，故决定 `NOT_ADOPTED`。共享主机未独占/锁频，保留所有样本，不推断未测的微架构原因。已恢复 CMake、runtime、gate compiler 和原 159 个生产工程文件的 SHA；候选 API 回归只留在冻结源和本目录。默认构建的恢复复核单独记录，不将它称为恢复版本重跑 28 项。
