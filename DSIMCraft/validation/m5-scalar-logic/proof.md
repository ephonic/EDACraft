# 存储采样投影与位运算候选

未采用，性能复测未通过，生产源码已恢复；以下仅描述被拒候选的正确性边界。第一版全部四态字节候选正确但真实收益未复现；其源和结果保存在 `../m5-scalar-gates/`。

设 P(0)=0、P(1)=1、P(X)=X、P(Z)=X。Liberty 支持的 NOT/AND/OR/XOR 对 X 和 Z 使用相同的未知规则，因此 P(F(a,b))=F(P(a),P(b))，NOT 同理；独立四态表逐项验证此性质。常量和两个存储状态值在 0/1/X 中。对 Boolean 表达式结构归纳可知，只在采样输入读取时执行 P，结果与原 GateState::logic(完整四态表达式) 一致。裸 pin 的 Z 最终也归一化为 X。该证明仅用于 ff/latch 的 control、next、clear、preset；组合输出和 three_state 保持 0/1/X/Z，不能投影 Z。

生成采样调用使用内部 `capture_normalized`，前提是四个参数均在 0/1/X（0/1/2）中；通用 V API 和四态 scalar API 仍自行归一化。`get_logic` 与旧 `GateState::logic(get(pin))` 相同，消除先编码 Z 再归一化的中间工作。原逻辑归一化后的 capture 算法逐字保留，包含 pending 值、双状态、冲突属性、初始化和 NBA hold。

采样表达式仍用 0/1/X=0/1/2；组合表达式改用 V 两个位平面的紧凑形式，0/1/Z/X=0/1/2/3。`get_packed` 读取 `(a&1)|((b&1)<<1)`，输出 `packed::value` 还原两个位平面，保留 Z，无需按 X/Z 分支重新分类。AND/OR 用已知零/一谓词计算结果；XOR 合并高位未知标志，并在未知时置两位为 X；反相将 Z 和 X 均映射到 X。两个编码域在生成器中显式分开，存储状态读取按各自目标编码输出，three_state 只在四态组合域求值。所有输入组合及两个编码域间的转换均对独立真值表穷举，不用二态代数折叠。

没有新增状态字段，不修改驱动、alias、唤醒、固定敏感列表或安装顺序。与原版重新生成的模型对照时，安装器之后的全部文本须相同，普通 RTL 除未用 helper 外相同。仍须完整 gate/RTL、VCS、有序波形、实际生成回滚与 sanitizer；不从表达式更短推断性能。
