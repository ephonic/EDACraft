# 原生压缩波形的中断恢复

新增 `python3 experiments/waveform/dwf.py recover interrupted.dwf recovered.dwf`。扫描连续完整 BLK1，验证元数据、单帧解压界限、CRC、四态值、时间和相邻检查点；复制原始 META/压缩块，只重建索引及尾部。输入不改，输出独占创建。末块不完整或最终索引缺失/损坏可恢复此前完整块；完整数据块损坏拒绝输出，不跳过损坏块。恢复后可继续使用 `unpack` 和 `window`。

正常 Reader 仍要求最终索引；共享数据块解析器和元数据形状校验。Python 3.14 优先内置 `compression.zstd`，旧 Python 可使用系统 libzstd，两个路径均保持单帧及有界解压。原生 C++ writer、编译器、两个 parser 和文件版本没有改动。相比 m4 已验收源，所有 `src/`、`include/`、`third_party/` 文件逐字相同；完整 SDF 的紧凑存储候选保留在独立冻结目录，尚未默认采用。

默认新增的延迟驱动 compact 内核测试及 generic/compact 五组生成程序对照继续保留；后者现能从两种默认接收端生成两份实际程序，不依赖默认采用紧凑候选。变化列表见 `changes.json`。本批源码包 411 文件，SHA256 `8981228c7cc6236d812d2619b480b21eed56c36465a0ca0c0c1e3add9e9401b9`。

恢复测试实际编译宽四态 RTL 内部延时及 INTERCONNECT/IOPATH/HOLD 组合模型，各运行 ordered/settled × raw/Zstd，共 8 个原生捕获，完整事件与原生 VCD 一致。连同控制记录、同刻毛刺及强制系统 Zstd 的捕获，共 428 个截断场景，逐个核对完整块前缀、原始压缩字节、全部事件和同 tick 时间窗口。完整 META/数据 CRC 损坏及 CRC 重算后的错误检查点被拒绝；原生 Zstd 最终索引帧损坏、CRC 合法但形状错误的索引可重建；已有输出不覆盖。

初版结果统计字段被事件变量覆盖，导致已执行原生用例在报告中分类错误。已修正变量名并重新运行；当前报告明确 8 个原生捕获和 4 个其他捕获，不把旧的错误分类报告作为验收。本批早期隔离树的 58 项日志使用紧凑候选 C++，仅保留历史；默认采用源以 `default-macos-ctest.log` 和 `linux/linux-ctest.log` 为准。

当前默认 macOS 完整 **58/58** 通过（252.49s，CMake 选 Python 3.12 系统后端）；另外 Python 3.14 内置 Zstd 的实际 428 场景通过。Linux 同一源包的干净构建/完整回归 **58/58** 通过（389.97s），实际使用 Python 3.13 系统 libzstd 后端。`collect_remote.py` 归档实际原生 C++、VCD/DWF、截断/恢复文件、失败损坏输入和完整日志；`verify.py` 核对源码、全部归档哈希、原生 VCD 对照及每个完整块前缀。

最终核对 **PASS**，见 `verification.json`：411 源码与两端清单/源包 SHA 一致，1,347 个 Linux 归档文件哈希一致，三个实际运行集各 428 个截断文件逐个核对，完整 SDF 的实际生成 C++ 与 m4 验收程序 SHA 一致。证据包 SHA256 `ff8d744f804cb7c5954e5fa2fc2504e907afe59ee7eb0eca26c6eff45abe9655`。这完成波形恢复里程碑，不表示整体 VCS 对齐完成。

另完成原始完整 SDF 的真实 8 分区请求，全部 300,909 单元仍落在一个有工作量分区，切边 0、lookahead 0；总共 332 个零延迟域中只有一个有单元负载。当前分析只利用 INTERCONNECT 的正延迟，未将 IOPATH 作为切边，也未分区 RTL 测试平台。它证明当前算法不能为此真实设计提供并行机会，不证明设计在其他算法下不可并行。完整生成 C++ 与 m4 已验收并执行程序逐字相同；原始输入前后哈希、全部 1,744,700 项覆盖、86,496 个未关闭检查和非负模式 23,051 个夹零更新均保持。后续并行实现需接入 IOPATH 边界及严格的延迟/取消消息协议；报告仍标记 `execution=serial`。

本次没有新的压缩率或速度声明。全状态检查点、64MiB 记录/32MiB 检查点限制、索引常驻内存仍存在；百万信号分组检查点、信号跳读、增量索引和异步压缩后续实现。只能恢复已完整写入的块，尾部字节数还包含被替换的索引，不表示丢失事件数。格式及操作边界见 [DWF 文档](../../docs/waveform-format.md)。
