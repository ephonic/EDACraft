# M201: array ordering and public UVM phase keys

Implement `sort`/`rsort`, optional default or named iterator `with` expressions, and `reverse` for one remaining fixed array dimension, dynamic arrays, queues and instance class queues. Keys can be integral (including signed wide values), real or string; class handles require a comparable key for sorting. Receiver and fixed subarray addresses are captured before reading values. Mutations use existing signal notifications, automatic frame storage and checkpointed container state; dynamic storage identity is retained.

The runtime computes keys once per element and merges index permutations in O(n log n). A bounded merge also handles unknown comparisons without passing a non-strict ordering to C++ std::sort. Equal/unknown ordering and with-expression side effect counts are not claimed to match VCS. `shuffle`, mixed runtime dimensions, associative ordering, unsupported class array storage and full UVM remain outside this implementation.
