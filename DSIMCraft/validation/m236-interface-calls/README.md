# M236 — runtime virtual interface subroutines

Bind the prototype signature/import permissions in the RTL parser, then bind actual method bodies separately for each elaborated interface instance. Functions dispatch to ordinary compiled functions with preserved return metadata. Tasks branch into existing resumable automatic task frames, retaining the selected instance during delay/reentry. Canonical interface signals, static locals and ordinary parameter/ref/output machinery remain authoritative. No library stubs or per-example special cases are used.

Ten fixtures cover default/named/ref/array/string arguments, typed wide/enum/real/array returns, nested calls, simultaneous class-task reentry, static instance locals, lexical time units and pure automatic event/wait functions after receiver rebinding. Nine same-source VCS outputs align; a receiver argument-side-effect probe deliberately retains its different target-binding trace. In that probe both simulators evaluate the base receiver once; dsim retains the pre-argument interface, while VCS uses the interface stored by an argument. It is not an alignment pass. Initial assertions assumed the former order and caused VCS Fatal with exit zero; the observer now asserts common invariants and prints the raw difference. The VCS harness explicitly rejects Fatal/Error output as well as nonzero exits.

Six protected compile boundaries are retained. VCS rejects five and accepts the side-effecting event-function control which dsim rejects. The original pure event probe has since become a positive test. VCS executes the retained null-function probe, whereas dsim diagnoses null; both reject the null task. These differences are explicit. The first native fixture used an uninitialized four-state call counter; it was initialized before final tests. String/array return dispatch was corrected to use its native representation rather than an invalid integral $bits query.

Verification uses --shared-functions, UVM_NO_DPI and native -O0, not a performance comparison or complete UVM certification.
