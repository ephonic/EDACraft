M208：类动态数组与随机动态整数数组。

支持独立对象堆内的一维动态数组、new[N](source)、值复制、size/delete、元素/packed 写入及 foreach；随机整数动态数组接入 Z3，先求长度再求元素，长度可关联多个数组与标量。元素阶段保留标量联合约束，支持枚举合法域、符号元素下标、模式开关、具名属性列表与失败原子性。对象数组/RNG/回调状态参与 checkpoint。

六个新增模型覆盖存储、耦合长度、继承/模式/回调、两阶段 UNSAT、96 位枚举和预测回滚。检查串行、时间轮、双线程，VCD/DWF/异步波形完整解码一致。VCS 使用相同源文件及断言，失败用例预期的三条 CNST-CIF 单独计数。前端及生成模型另做 ASan/UBSan。

这是有限范围的动态数组支持。randc 数组、类句柄/实数动态数组、类内多维/固定数组、随机数组 reduction/locator、同一约束原子内混合 size 与随机元素、std::randomize 数组和 timed/NBA 元素写仍明确拒绝。公开未修改 UVM 的首错从 m_data[] 推进到 uvm_tlm2_generic_payload.svh:372 的随机类句柄数组 m_rand_exts[]；完整原版 UVM 尚未运行。
