# M136：SVA 固定连续重复

新增 `expr[*N]`，支持 1..256 的常量计数，按实例参数展开后进入既有固定周期序列。支持边界及未实现语义见 [专题](../../docs/sequence-repetition.md)。门级 parser 与八个 runtime 头文件没有改动。

五个同源模型覆盖 assert/assume/cover、重叠与非重叠蕴含、直接序列、前导/中间/零延迟串接、四态失败、采样函数、异步取消、参数化/generate 克隆、单次/256 次边界，以及真实双分区。TRACE 期望来自远端 VCS 原始执行；双分区模型以全波形和最终输出值验收，不增加会把独立域串行化的打印观察器。

新回归检查 serial、time-wheel、threads=2 配置的完整逐信号有序波形，以及在途状态的预测提交和回滚；计数/总跨度/阶段限制、未实现语义和受保护输出文件另设正反例。Parser 重复清理测试加入参数化重复，ASan/UBSan 沿用完整语义测试；不启用 LeakSanitizer。

源码、平台回归、VCS 对照、稳定入口和原始证据的身份记录在本目录 JSON。VCS 生成代码和二进制仅留在远端私有工作目录，不进入仓库或证据归档。没有新的性能比或完整标准覆盖声明。
