# 0.13.0 共享门级进程与 alias 缓存

本批继续性能主线：门级模型改为每 DUT 共享无捕获回调、实例携带紧凑 handler/cell ID；一般 RTL 闭包仍拥有独立的可复制 Action 表，模型 context 自动注册生命周期与快照。进程顺序、等待代数及 Active/Inactive/NBA 阶段不变。alias 成员资格在连接定型时缓存。接口与证明边界见 [共享编译进程](../../docs/compiled-processes.md)。

## 同轮五版本测量

固定 0.12.0 作为原版，GCC 11.5 / `-std=c++17 -O2`，VCS W-2024.09 默认优化，同一 `10.131.254.103` 主机。非规则 XOR/DFF 反馈、200 周期、`2N+1` 个实例；每工具预热一次，轮换顺序各跑三次，自己的计时任务串行。共享主机未锁定 CPU/频率，原始范围与全部计时文件保留。

10 万触发器的中位数：

| 版本 | CPU 秒 | 墙钟秒 | RSS KiB |
| --- | ---: | ---: | ---: |
| 原版 0.12.0 | 9.14 | 9.185 | 110600 |
| 仅 alias 缓存 | 8.84 | 8.878 | 114960 |
| 仅共享回调 | 6.16 | 6.198 | 88400 |
| 组合 0.13.0 | **6.51** | **6.538** | **88644** |
| VCS | **5.31** | **8.015** | **160572** |

组合较同轮原版 CPU 减少 **28.77%**，RSS 减少 **19.85%**，CPU 为 VCS 的 **1.23 倍**。仅共享回调的中位数更低，两项收益不完全叠加；不隐去此差异，也不把不同轮次的 VCS 数值拼在一起计算收益。补充复测使用原二进制、固定 CPU 0、预热一次后交替五次：仅回调/组合 CPU 中位数为 **7.57/7.40 秒**，RSS 为 84,320/84,392 KiB。此轮组合略快约 2.2%，没有复现主表的反向排序；共享主机没有独占 CPU 或锁频，不能证明稳定的缓存叠加收益。保留两项实现，不用此轮数值替换主表或另算 VCS 差距。原始补充数据在 `remote-verified/build/affinity-performance/`。

1 万档 CPU 原版/缓存/回调/组合/VCS 分别 0.43/0.42/0.38/0.38/0.87 秒；不把小规模启动优势推广到实际设计。独立 cache 首轮 10 万档 9.55→8.83 秒、VCS 6.08 秒，属于另一个实验，只用于决定进入五版本比较。

1 万档 Callgrind 从原版 2,565,506,331 到组合 2,430,360,679 条指令；这是指令归因，不是 CPU 百分比或 Valgrind 时间加速。运行时收益以正常未插桩测量为准。Process 在本地 ABI 从 48 降为 24 字节，Signal 仍为 96 字节；RSS 包含全部模型和堆分配，不用局部 sizeof 代替它。

主表最多采样 64 位并计算独立递推 checksum。完整事件等价另由 18 个有序波形流验证；理想零延迟库不代表真实 foundry/SDF 仿真速度。

## 普通 RTL 与波形

对同一输入分别用 0.12.0 /0.13.0/VCS 编译：算术 20 万次 CPU 中位数 0/0/0.49 秒（计时分辨率不足），时钟/NBA 20 万周期 0.03/0.03/0.56 秒，64 进程扇出 20 万周期 0.56/0.56/1.07 秒。没有从这几项观察到明显 RTL 退化，不作一般性保证；墙钟包含 VCS 启动/许可，完整表见 [分析](analysis.json)。

1 万 ff /200 周期，同一个已编译程序关闭捕获 / 全网 VCD / 全网 DWF 的 CPU 中位数为 **0.39 /0.58 /0.61 秒**；无波形代码的独立程序为 0.36 秒。全网文件为 9,317,158 /5,646,864 字节，压缩约 1.65 倍，字节数与前批相同。仅共同顶层 VCD 的 native/VCS CPU 为 0.41/0.91 秒，不能把全网与顶层的开销直接比较。三次完整原生 VCD/DWF 和顶层按位比较从原始文件复核。本批没有修改压缩格式或 Python 原型，不能将进程优化称为新 codec 收益。

复核：`python3 validation/m5-compiled-process/analyze.py`。它重算原始 CPU/RSS、输入与生成源码 SHA、所有波形和 VCS trace，不只检查 PASS 标记。初次远端启动在解包前调用脚本而退出 127，未启动编译/测量；[启动失败](launch-before-unpack.log) 保留，修正解包顺序后使用同一冻结包运行。

最终独立分析已通过：冻结实现/独立 parser、全部原始计时与输入、25 组 VCS、18 条有序流、波形成本、固定 CPU 补充实验、11 个 SDF 参考及 sanitizer 证据均复核成功，详见 [analysis.json](analysis.json)。
