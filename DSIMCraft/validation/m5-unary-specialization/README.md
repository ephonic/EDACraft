# 固定 Liberty 反相专用化

**已采用**，作为当前 0.13.0 工程版本的增量优化。以固定源包为原版，只修改两处固定反相代码生成，并增加四态穷举回归；没有包含已撤回的模型专用 handler。最终决策与独立重算见 [decision.json](decision.json) / [analysis.json](analysis.json)。

## 等价边界

Liberty 前缀 `!` 与后缀 `'` 原先生成 `unary("~", expr, 1)`，执行时构造操作符字符串并分派。现在直接生成 `inv((expr).size(1))`。原函数第一步就是 `size(1)`，其 `"~"` 分支调用同一个 `inv`；因此保留宽度归一化以及 0→1、1→0、X/Z→X。没有修改一般 RTL 的逻辑非、算术或 reduction，也没有改变任何进程、事件、驱动和检查点位置。RTL 与门级 parser 继续独立。

真实设计活动前缀显示一般 unary 函数自身约 4.45% 指令，另有字符串比较热点。这只用于选择候选；实际收益按未插桩的完整设计 A/B 测量。

## 验证方法

- 新增 `tests/gate/unary.py`，四个输入穷举 256 组，核对 11 个输出。独立标量真值表覆盖前缀/后缀、嵌套、Liberty 优先级及三态控制，与独立 Verilog 模型核对。
- 本地与 Linux 完整 CTest；15 组门级 native/VCS 各三次，再加新增用例的 VCS 三次。18 条完整有序波形流与固定原版逐事件一致，完整回归包含生成检查点/预测失败重放。
- 新 ASan/UBSan 编译器和实际生成的 256-pattern 程序；二进制与符号记录在 `sanitizer-provenance.json`。运行时/并行源码未改变，没有把前批 TSAN 重记为本批验证。
- 不含 Liberty 反相的 1 万 ff 反馈网络，重新生成 C++ 并要求与固定原版逐字节相同，不在无变化负载上宣称加速。
- 完整原 barr_modmult 的 300,909 个单元、111 种模型、完整 1.2GB Liberty、128 组原 RTL golden；内部 256/257 位保留，TB 外部端口按 64 位 limb 适配。原版/候选/VCS 使用同一输入，每次运行核对全部输出，均无 SDF/波形。
- 所有本批远端正确性作业完成后，原版/候选/VCS 各预热一次、按旋转顺序串行运行三次。复用已验证且 SHA 固定的原版与 VCS 二进制；生成/编译成本单独保存。共享主机没有独占或锁频，不能推广为所有设计的稳定加速比。

源冻结包 `/tmp/dsim-unary-source.tar.gz` 的 SHA256 为 `8d67a3682a728bc4791e5c4ac9a5223b88be4086b18af44e933c8eac645aec71`，清单见 `source-snapshot.json`。参考源包与所有旧证据保持不变。`freeze.py`、`run.sh`、`measure.py` 可重建隔离实验；`collect.py` 封存原始日志，`analyze.py` 重新计算 CPU/RSS 中位数、golden、四态 oracle、有序流和源码边界。

初次新增测试的独立 Verilog 模型把双重反相写成 `~~A`，Icarus 拒绝该词法形式；修正为 `~(~A)` 后通过。初次失败日志保留在 `build-unary/unary-smoke/`，没有修改仿真器语义以适配错误参考。

实际 SDF 回标/脉冲、自动并行分区和压缩编码继续按总计划推进；本批是零延迟执行优化。

## 实测结果与采用决定

完整真实设计，预热后每工具串行交替三次，CPU/墙钟为秒、RSS 为 KiB：

| 工具 | CPU 中位数 | 墙钟中位数 | 峰值 RSS 中位数 |
|---|---:|---:|---:|
| 固定原版 | 17.31 | 17.361 | 104,508 |
| 固定反相专用化 | 13.71 | 13.757 | 104,064 |
| VCS | 7.12 | 11.306 | 191,172 |

同轮候选为 VCS 的约 **1.93 倍 CPU**；原版三次 CPU 为 13.67/17.39/17.31s，候选 13.41/14.40/13.71s，VCS 6.60/7.12/7.34s。共享主机波动明显，因此不把首轮 20.8% 当作稳定收益。VCS 墙钟包含进程/运行环境启动成本，与 CPU 差距分开看。

补充使用同一组二进制，固定 CPU 0、各预热一次、五次交替：原版 CPU **17.29s**、候选 **14.82s**，降低 **14.29%**；墙钟 17.354/14.885s，RSS 104,560/105,028 KiB。五组按迭代配对的候选均更快，但没有内存下降结论。原版原始 CPU 为 16.37/17.29/16.41/17.99/19.15s，候选 14.48/14.82/15.13/14.64/18.73s；仍未独占/锁频。这一轮没有重跑 VCS，不能用 14.82s 除以上一轮的 VCS 数值。

候选完整生成/编译墙钟分别为 27.180/18.595s，峰值 RSS 1,974,576/1,994,044 KiB；与运行阶段分开。原版/候选 ELF 9,062,864/9,048,216 字节。此处只测当前生成/编译成本，没有旧版同轮成本变化结论。

本地/Linux CTest **23/23**，分别 268.89/474.56s；15 组既有 gate/native/VCS 各三次、新增 256-pattern VCS 三次、18 条完整有序事件流、生成回滚，以及新 ASan/UBSan 的两项实际二进制通过。所有真实计时和预热运行都核对全部 128 组 golden。无反相反馈模型生成 C++ SHA 双方均为 `91d80ba36a54520a19f272dad498ef4c8943ef8e127eba82fd033db555578e08`。

[封存原始证据](evidence-archive.json)：**1,429 个文件、15,632,696 字节**，`/tmp/dsim-unary-evidence.tar.gz`，SHA256 `0a3392d72f1a9d1ce8839d6a79317c0a65267c389205a98a7bd0ab53415c497c`。固定 CPU 补充驱动另由 `followup-driver.json` 固定，未覆盖首轮源冻结包；全部原始日志在 `remote-verified/`，analyze.py 不只读取 PASS 标签。
