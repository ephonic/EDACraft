## 实际减少的调度工作

乘除法过程 0..8 组成一个稀疏批次。共享时钟的成员为 0 和 7，复位为 1 和 8，其余输入仍触发原来的对应成员。一个输入变化只生成一个含订阅成员掩码的 FIFO 令牌；不同输入的通知分别排队，已排队成员通过 armed 位去重。

成员仍须连续、等待点连续、纯整网复制、唯一驱动、无初始化/别名，批次内部禁止任何读写依赖。不跨过已有同敏感列表直线批次；只有确实共享输入的片段才新增合批，尾部不共享的过程不纳入。输出端口连接补全 continuous_wait IR，使中间的输出桥接不再阻断静态分析。

共享输入的已知掩码生成直线专用分支；少数部分武装掩码按原成员顺序执行。Ready 原有填充容纳 uint16 成员掩码和 uint8 成员数，条目仍 8 字节，省去稀疏批次的第二份掩码队列及重复 push/pop。没有稀疏批次的模型不定义 DSIM_MASKED_COMB_REGION_ENABLED，继续使用 M121 热路径。

同一 200000000 tick 前缀的乘除法计数：Ready 入队和出队各 **261903→221894**，减少 **40009（15.28%）**；watcher **35→33**。43049 个物理批次覆盖 83058 个逻辑成员，83058−43049=40009，与队列节省精确守恒。诊断统计单独构建，不用于计时，见 [scheduling-stats.json](scheduling-stats.json)。

非统计 Callgrind 指令 **80072568→79085826（1.23%）**，执行步均为 **1242666**，全信号状态哈希均为 **6725625808751781491**。见 [profile.json](profile.json)。前缀物理计数、前缀指令与完整负载耗时分别报告，不跨单位外推。

## 功能边界与验证

每个逻辑成员仍计一次调度加三条指令，不删逻辑赋值或中间值发布。预算不足时在原 FIFO 位置展开成原过程，随后永久走原 PC 路径。掩码与成员数由 ReadyQueue 持有、随检查点深拷贝，支持多个待执行输入通知的恢复和预测拒绝重放。NBA 全批提交边界保持不变；force、复杂等待、多驱动、宽值、时序门级、实际多分区等继续保守回退。

发布回归覆盖八组模型、72 份完整 ordered/settled 波形、1576 组精确预算/全信号状态、8 次预测，以及 2504 个完整内核状态。新增两个输入的交叠订阅、同槽多次通知、多令牌待执行检查点、预测拒绝及重放；测试静态断言 Ready 仍为 8 字节。另八项相关内核、默认/参考稀疏内核和真实生成模型 ASan+UBSan 通过，见 [regression.json](regression.json)、[kernels.json](kernels.json)、[sanitizers.json](sanitizers.json)。

同源 VCS 对照：cohorts/boundaries/diagnostics/masked 四个原始源的 30 行 TRACE（各观察进程内的次序）和 269 位完整 settled 时间线一致。ports 原始源的 34 位完整 settled 时间线也一致，但 dsim 零时刻有额外一次 `TRACE ports xx xx`。冻结 M121 与 M122 在原始 ports 源上的完整 stdout 和 ordered VCD 逐项相同，证明该差异先于本轮，见 [ports-original.json](ports-original.json)；最初的 VCS 打印对照失败保留在 [vcs-initial-comparison.json](vcs-initial-comparison.json)，未计作原始 TRACE 全通过。

仅在 VCS 观察探针副本中将 ports 打印观察器延后 1ps 武装，设计和激励不变，两边使用同一副本，5 行 TRACE/34 位时间线一致。总计五个探针 35 行 TRACE/303 位时间线通过，源哈希及明确的 preparation 见 [vcs.json](vcs.json)。dsim 原始源默认/参考和跨版本的严格全局输出/有序波形比较没有放宽。
