# M234 — virtual interface and real UVM DUT verification

Add typed virtual interface handles, modports, typedef/generic class parameters, class properties, constructor/formal transport, alias return values and null/type checks. Resolve interface member types in the definition's compilation-unit scope. Handles identify actual elaborated interface instances; reads/writes/ref/NBA use canonical signals. Dependencies include all compatible instances. Rebinding follows VCS event expression behavior while captured NBA/ref targets keep their original identity. Callback dereferences are deferred until the wait is armed.

Eleven models pass three modes (33 complete ordered captures across the original ten-model suite and the final lexical fixture). All match same-byte VCS TRACE exactly. Frozen release checks run all eleven together. Eight illegal bindings/views/operations are rejected by both compilers; null read/write/ref are rejected at runtime by both. An early VCS boundary harness expected `Error-[...]`; its first run stopped on VCS's `Error: uninitialized virtual interface object`. The corrected harness recognizes both actual diagnostic forms and completes all boundaries.

Eight frontend/native ASan/UBSan cases pass with complete C++/wave identity. Four forced failed predictions compare complete equal-horizon waves, including waits/refs after binding. Original interface regression passes 31 captures, four failed predictions and 19 compile rejections, including its two actual parallel partitions. Initially it caught an interface accidentally accepted as an ordinary integral port; fixed, and the complete suite rerun passes. Earlier compound receiver capture and inactive-null-wait failures are retained in raw evidence.

The unmodified complete Accellera UVM 2020.3.1 source (181 files, tree SHA 65296510b8010f96fccb3cd294936a68ec1fc7f71c9fe540af181bfddf45fe6f) runs a real DUT path: `uvm_config_db#(virtual interface)` → sequencer/driver → signal NBA writes → DUT → independently clocked monitor → analysis scoreboard. Transactions 100/101/102 give DUT count 3 / sum 303 and the same scoreboard result, zero errors/fatals. All TRACE, test hash and library tree hash match VCS. The sanitized complete-library frontend and native program both pass, with complete generated C++ identical to the normal run.

Tests use UVM_NO_DPI and native -O0, not a performance comparison. This is a supported subset, not full virtual interfaces/UVM. Explicit type parameter overrides, virtual subroutine calls, virtual clocking access, full unpacked transfers/interface arrays and virtual-handle $cast are outside this change. Complete object-graph randomization, DPI open arrays, sample-argument coverage and the 8192-bit packing case remain gaps. See [scope](../../docs/virtual-interfaces.md).

Raw artifacts: `dsim-test/evidence/m234-virtual-interfaces/`. The initial frozen release attempt caught a regression-script argument mismatch: the publisher supplies CMakeCache.txt as a third argument, which the optional case filter treated as a case name. The candidate was rejected and the previous stable entry retained. M235 fixes this contract and publishes the combined source. The combined M235 release completes both immutable deployments and all actual-entry checks.
