# M184 opaque chandle / DPI

Implements distinct nullable C handle types in the RTL frontend. A handle occupies 64 storage bits but is not an integral value or a class object. Fixed unpacked arrays, typedefs/type parameters, class properties, input/output/ref arguments, function returns, comparisons, case, direct conditions and typed conditionals are supported. DPI maps input/result to void* and output/inout to void**, including context callbacks. Blocking intra-assignment delays retain handle identity across suspension; delayed NBA uses the captured pointer value, and case labels require matching opaque types. Generated code checks pointer storage width. Waveforms omit opaque pointer storage. Impure foreign calls retain the existing prediction barrier.
