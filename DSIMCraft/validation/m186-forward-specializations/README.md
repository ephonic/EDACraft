# M186：前向参数化类的特化

修复前向声明类在完整定义之前被 typedef 特化时过早展开类体的问题。先建立规范的特化类型身份，外围声明完成后通过延迟语义队列展开类体；实际成员访问仍使用既有按需展开路径。没有跳过基类或成员的语义检查。RTL 与门级 parser 保持分离，运行时调度未修改。

新增两个同源 SV 模型验证早/晚及按名/位置别名同一性、ref 函数参数、基类虚分派、65/129 位模块克隆、递归类句柄。新增五个拒绝用例覆盖缺失/非类基类、循环继承、参数缺失和不同特化的句柄赋值。重复解析测试同时修复 clear 未清空失败语义队列的问题，防止节点释放后再次处理。
