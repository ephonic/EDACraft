补齐实例类标量 event 的执行语义，支持继承、句柄别名共享身份、不同对象隔离、类方法/自动任务中的事件控制和 -> / ->> / 延迟 NBA 触发。事件控制进入等待时仅求值并绑定接收者一次；条件 wait 按当前句柄重新求值。支持 triggered、相关边沿/混合事件和 iff 守卫，实例事件和订阅状态参加预测回滚。

动态事件身份使用对象堆依赖通知，独立订阅按实例缓存并按等待代次过滤，避免旧绑定误唤醒。身份属于运行时状态，保留静态调度拓扑；不导出为未声明的波形信号。动态 fork 复制时清理订阅缓存。

八个执行模型、十二份明确拒绝、三种原生调度内核，以及重复 parser 语义/清理检查覆盖上述行为。与 VCS 同源比较输出；前端、生成模型、内核用 ASan/UBSan 验证。冻结七组及 mandatory parser/Liberty DB 后发布，实际稳定入口重新生成 C++ 并复用相应已验证原生模型复跑输出/完整波形。

事件数组、event 变量别名/初始化和参数传递、const/rand event、实例事件 wait_order、挂起 NBA 赋值的实例事件控制仍不支持；不以非阻塞事件触发已支持推断这些能力也完整。
