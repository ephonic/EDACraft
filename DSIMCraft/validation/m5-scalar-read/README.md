# 紧凑网直接编码读取试验：不采用

基于已采用 LUT 的同一完整生成模型，绕过临时 V 对象，直接读取紧凑网/晋级后端的四态位平面作为查表索引。只改生成源的 286 个真实设计读取点和 2 个反馈读取点，未改生产 runtime、驱动、通知或过程顺序。

GCC 11.5 / C++17 O2，固定 CPU 0，共享主机未锁频。原版/候选分别重新编译、预热一次，五轮交替串行执行；真实设计每轮核对完整 128 golden，反馈也核对全部输出。真实设计配对收益中位数 0%，仅两对变快；反馈配对收益中位数约 1.82%，但有明显阶段波动。真实设计未过预设 3% / 至少四对改善门槛，不采用、不进入默认编译器。不运行新 VCS，不给出新的 VCS 比例。

`screen-verified/` 保存两种负载的实际源码、二进制、全部 time/stdout/stderr 与驱动。`verify.py` 从原始计时和完整输出独立重算，核对二进制/源码 SHA；`decision.json` 保存证据归档 SHA 及逐文件哈希。隔离试验驱动为 `experiments/scalar_read/screen.py`。
