# M187：默认实参读取前序形参

默认表达式在声明处解析，只导入前序形参，自身名字、后续形参和函数体局部变量不参与查找；缺失时继续查找外围声明。调用端先转换并保存每个实际参数，后续默认值读取这些值，不重复求值。函数、任务共用绑定逻辑，包含构造函数、继承、虚调用静态原型、extern 和 modport 原型。嵌套调用使用唯一临时别名，默认值的类成员访问绑定接收对象。没有默认参数的调用不生成额外别名；只有后续默认值可能读取的参数才提前执行状态转换。调度器和门级 parser 未修改。

修复原始函数 AST 的父指针建立条件（原本在验证失败时设置），以支持原始 package 函数与 clone 一致的声明溯源。增加重复解析、符号身份、失败后恢复测试，以及五个执行模型，覆盖副作用、链式/按名/空参数、递归、129位值、符号扩展、二态转换、实数、字符串、枚举、选择、类克隆、虚函数/延迟虚任务、构造函数、ref 读取和原型默认值。

仍保留明确边界：默认值写入前序形参、依赖 output 形参存储、依赖未打包数组/多维 packed 选择、以先前形参作为新的 ref 默认绑定；这些路径不会静默读取尚未复制的形参存储。VCS 对前四个非法作用域反例同样拒绝，其余存储依赖用例的接收差异单列。当前 VCS W-2024.09 拒绝带默认值的 modport import 原型；因此 default_prototypes 原样模型仅记 dsim 验证，另有只把 modport 改为名字导入的 VCS 变体，不混为同源通过。
