# 功能与速度实现批次

生产代码新增两项：

- 无波形支持的 SDF 编译自动折叠最终全零 IC/PORT 输入通道；`--no-gate-fold-zero-inputs` 保留原通道。显式波形支持及 `$dump*` 自动启用时保留输入通道，避免改变初始化的有序 delta 波形。
- RTL 普通过程、阻塞赋值内部及 NBA 内部运行时整数表达式延迟；入口采样、模块 timescale、X/Z 零延迟、宽整数转换、缩放溢出、并行读依赖及现有回滚状态。

本地编译器：`build-feature-speed/dsim`。新增两项 CTest 通过；动态延迟含38份捕获、串行/时间轮/双线程、待事件回放和运行时溢出；默认折叠含非零路径、检查、多驱动和非零 IC 四类场景，及自动 dump 的保留策略。旧阻塞/NBA/连续延迟和时间基准四项通过。
