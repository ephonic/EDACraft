# 不改变监听布局的固定 any-edge 属性缓存

本项隔离试验，默认runtime不改，不叠加先前失败的监听压缩、fallback复用、队列或模型handler变换。

完整真实设计和100k触发器反馈的当前runtime计数表明：非零时刻分别扫描61,209,513 /18,545,776个紧凑网监听项，全部是固定any-edge，代际和边沿筛选数均为0。真实变化40,090,378次，反馈27,859,644次；这只是行为计数，不是指令比例、计时或提速。整个真实128 golden与反馈golden一致，当前/旧基线的完整规范化预处理相同。旧压缩方案曾使反馈回退，不能据此省略反馈门槛。

候选在CompactSignal尾部既有填充放置一个pure_fixed_any标记。固定any-edge注册保持true；动态或固定边沿访问监听列表时一次保守置false，不再恢复。通知时true分支仅检查waiting，false分支走原代际/边沿逻辑。Watch的16字节布局、vector、每个重复项的顺序和全部generation保留；紧凑网槽在macOS arm64/Linux x86_64仍须48字节。alias/额外驱动不改变监听语义，仍使用相同列表；深复制必须复制标记，动态首次注册后回滚也恢复它。已有fixed进程禁止切换等待模式/定时器的检查不变。

筛选预声明：当前已采用runtime+完整模型，GCC11.5 C++17/O2；先编译全部baseline/candidate，确认计数作业已结束，才在同一允许CPU各预热一次、五对交替运行。每次检查真实完整128 golden及反馈golden，保留全部time/stdout/stderr/源/二进制、编译成本、RSS及CPU。真实配对CPU收益中位数≥3%、至少4/5改善、反馈中位回退≤3%才进入独立7对真实/5对反馈；复测真实收益≥3%、至少5/7改善、反馈回退≤3%。不混用旧VCS分母，不删慢样本；共享主机/未锁频和外部负载要记录。

通过筛选/独立复测后仍须实际最终编译器生成程序、两平台完整回归、三态/多驱动/四态边沿与stale动态槽、首次一般监听转换前后快照/预测拒绝及提交、实际内部SDF待交付事件和全量ordered/settled波形、实际ASan/UBSan、普通RTL预处理保持及新同轮VCS计时。未通过则不采用。标记是结构属性缓存，不改变任何事件、驱动身份、初始/delta行为或单元等价关系。
