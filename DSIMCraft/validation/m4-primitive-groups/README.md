# RTL 原语实例分组

本批修正 RTL parser 把无名原语端口逗号与实例间逗号混淆的问题。`and (q,a,b), named(r,a,b), (s,a,b);` 现在建立三个完整实例，支持有名、无名和混合声明，以及裸 `#2`、`#D` 和带括号的常量延迟。实例的父节点为实际 gate group，端口组的父节点为对应实例；临时列表由节点池回收。语法源及 Bison 3.8.2 生成文件同步更新；隔离重生成逐字一致。原有33个 shift/reduce、69个 reduce/reduce冲突及两个 generate规则警告未增加，也没有在本批解决。

RTL 与门级 parser 保持独立；本批没有改动门级结构 parser、SDF 注解算法、runtime、并行或波形实现。原语数组、多输出、非 strong 驱动等仍明确拒绝。
