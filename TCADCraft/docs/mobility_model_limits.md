# Arora 接口公式与极限

当前参数集的接口约定为

`mu = [mu_min + (mu_max-mu_min)/(1+(N_total/N_ref)^alpha) * (T/300)^beta] * 1e-4`。

这里浓度比使用 cm^-3，最终迁移率单位为 m²/(V·s)。温度因子只作用于浓度相关项。电子和空穴在 300 K、零掺杂时分别恢复 1417 和 470.5 cm²/(V·s)；高掺杂极限分别为 52.2 和 49.9 cm²/(V·s)。原生调用以 Nd+Na 为散射浓度；当前器件接口只保存净掺杂，不能据此声称支持独立补偿浓度的散射。

2026-10-30 修复了原生实现遗漏加性 `mu_min` 的问题，独立热反馈校验器同步按上述公式验收。旧的遗漏项不再能由相同错误的校验公式获得通过。零迁移率绝缘节点的器件处理保持；常数迁移率算例不受影响。历史封存副本保留原有实现和验收结果。

2026-10-30 另行修复了 Arora 和低温模型共用幂函数的 `double` 降精度转换，改用标量后端的 `powq` / `powl`。12 个由 Python Decimal（100 位十进制精度）独立生成的参考值，以及低于 double 分辨率的温度扰动检查，用于检出该问题。扩展精度构建下的局部模型不再先丢弃输入和幂运算精度。

这些修改恢复现有接口公式并保留计算后端的精度，尚未建立参数集与 Sentaurus Arora 模型的完整对应。113/64 位表示测试构建的标量尾数位数，不是整个器件求解的有效精度保证。局部迁移率、电流与热反馈检查不构成完整器件能量闭合或商业验证。
